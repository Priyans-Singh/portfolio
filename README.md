# Priyans Singh — Agentic AI Engineering

Static portfolio published from the repository root with GitHub Pages.

## Publish

GitHub Pages should use **Deploy from a branch**, **main**, **/(root)**.
After pushing `main`, the site is available at https://priyans-singh.github.io/portfolio/.
No build step or dependencies are required.

## Preview and edit

Run `python3 -m http.server 4173` from this directory, then open http://localhost:4173/.
Edit `index.html`, `styles.css`, `app.js`, `walkthroughs.css`, and `walkthroughs.js`.
All local assets use relative paths, including the logos in `logos/`, so the site works under `/portfolio/`.

Project illustrations become looping previews on hover or keyboard focus. On phones, tap to preview. Theme preference is saved locally; reduced-motion preferences are respected.
