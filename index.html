Specialist agents working with authorized business data.

  • A2A coordination
  • Identity propagation

The exploration

Use a coordinated agent workflow to connect natural-language requests with structured business data.

What I built

A personal BI platform with a LangGraph orchestrator and KPI, market-intelligence, and remediation specialists connected through A2A. User identity propagates through the workflow so agents can access the user’s Google Sheets with the provided authorization.

System shape

User question and identity → LangGraph orchestrator → A2A-connected specialists → authorized, read-only Google Sheets access → response.

Observability and evaluation

Shared session IDs and trace IDs correlate execution across agents. Evaluations are a core part of assessing the agent workflow alongside distributed tracing.

Project context

A personal/hackathon project and AI for Bharat semifinalist. It explores coordinated agent reasoning over business data, with read-only access to the connected spreadsheet.

SERVICES & COLLABORATION

How I work.

I lead agentic AI exploration in my current role. That means investigating possibilities—and making the tradeoffs concrete enough to act on.

01↗

Resolve the technical uncertainty.

For teams deciding what to build or which agent platform to use. A focused investigation with an agreed question, time budget, and decision to make.

  • Requirements and platform assessment
  • Targeted technical spike
  • Architecture recommendation and tradeoffs
  • Implementation scope and next steps

AWS is my strongest hands-on environment. Other cloud ecosystems are scoped as technical discovery.

02↗

Take the workflow into the application.

For teams with a prototype or a defined use case. Connect the agent to the surrounding systems, deploy it, and make ownership clear.

  • Agent and business-system integrations
  • Backend and streaming implementation
  • AWS deployment and distributed observability
  • Agent workflow evaluations
  • Documentation and technical handover

A bounded integration is a good starting point. Full application builds are possible when the scope fits.
