Specialist agents working together on business data.

  • Dashboards generated in the platform
  • User-authorized Google Sheets access
  • Tracing and evaluation across agents

The idea

Turn a plain-language question into an analysis of the user’s connected business data.

What I built

I built a LangGraph orchestrator that coordinates KPI, market-intelligence, and remediation agents through A2A. The workflow carries the user’s authorized identity so agents can read the connected Google Sheets and return a dashboard with an explanation.

Read technical details+

How the system works

User question and authorized identity → LangGraph orchestrator → A2A-connected specialists → read-only Google Sheets access → dashboard and explanation in the platform.

Tracing and evaluation

Shared session and trace IDs link work across agents so a request can be followed end to end. Evaluations assess the agent workflow alongside those traces.

Project context

A personal/hackathon project and AI for Bharat semifinalist, exploring coordinated agent reasoning over business data with read-only spreadsheet access.
